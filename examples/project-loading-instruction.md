# Project-owned loading instruction example

Add a rule like this to the consuming project's `AGENTS.md` or equivalent:

> Before changing Python tests, read `.github/guidelines/python-testing.guideline.md`.
> Before creating a commit, read `.github/guidelines/commit-message.guideline.md`.
> Load `.github/guidelines/ui-design-system.guideline.md` for interface work.

The project owns these loading conditions. Installing a guideline never injects or activates it
automatically.
